# 📊 Adult Income İstatistiksel Analiz Projesi

Bu proje, Python kullanılarak Adult Income veri seti üzerinde gerçekleştirilen veri ön işleme, veri temizleme ve istatistiksel analiz çalışmalarını içermektedir.

Projede veri analizi süreçleri uygulanmış, farklı grafikler oluşturulmuş ve veri seti üzerinde çeşitli istatistiksel incelemeler gerçekleştirilmiştir.

---

# 🛠️ Kullanılan Teknolojiler

| Teknoloji | Kullanım Amacı |
|---|---|
| Python | Ana programlama dili |
| Pandas | Veri işleme |
| NumPy | Sayısal işlemler |
| Matplotlib | Veri görselleştirme |
| Seaborn | İstatistiksel grafikler |

# 📊 Oluşturulan Grafikler

Proje kapsamında veri analizi süreçlerinde çeşitli istatistiksel grafikler oluşturulmuştur.

Bunlardan bazıları:

- Histogram grafikleri
- QQ Plot analizleri
- Boxplot grafikleri
- Dağılım grafikleri
- İstatistiksel karşılaştırma grafikleri
